# Visuels des lots de la tombola

Déposer ici les photos des lots (la villa du gros lot, notamment).

- Format : JPG pour les photos, largeur ~1200 px, compressé (< 300 Ko).
- Nommage : en minuscules, sans accent ni espace — ex. `villa-cote-landaise.jpg`.
- Renseigner ensuite le chemin dans `src/data/lotsTombola.js` :
  `photo: '/lots/villa-cote-landaise.jpg'` (et adapter `photoAlt`).

Les logos des partenaires vont dans `/public/logos/`, pas ici.
